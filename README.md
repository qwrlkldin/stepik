# Решения заданий по автоматизации с Selenium

В этом репозитории собраны решения практических задач по автоматизации браузера с помощью Python и Selenium. Все решения выполнены в рамках изучения методов работы с веб-элементами, alert, select, файловыми загрузками и другими возможностями Selenium.

## Содержание и выполненные задания

1. **Поиск и заполнение форм**
   - Использование методов `find_element` по различным локаторам: `By.ID`, `By.NAME`, `By.CLASS_NAME`, `By.CSS_SELECTOR`, `By.TAG_NAME`.
   - Заполнение текстовых полей, выбор чекбоксов и radiobutton.
   - Отправка формы кнопкой Submit.

2. **Работа с текстом ссылок**
   - Поиск элементов по полному тексту с помощью `By.LINK_TEXT`.
   - Поиск элементов по подстроке текста с помощью `By.PARTIAL_LINK_TEXT`.

3. **Массивные формы**
   - Использование метода `find_elements` для поиска всех input-элементов на странице.
   - Автоматическое заполнение большого количества полей через цикл.

4. **XPath и уникальные селекторы**
   - Поиск кнопок и элементов по XPath, включая выбор элементов с определённым текстом.
   - Проверка уникальности селекторов для разных версий страниц.

5. **Капчи для роботов**
   - Работа с `checkbox` и `radiobutton` для проверки простых тестов.
   - Считывание текста элементов через `.text` и вычисление математических выражений.
   - Получение значений атрибутов через `.get_attribute()`.
   - Вычисления с использованием функции `calc(x) = log(abs(12*sin(x)))`.

6. **Работа с выпадающими списками**
   - Выбор нужного значения из select по вычисленным результатам.

7. **JavaScript и прокрутка**
   - Использование метода `execute_script` для скролла страницы и взаимодействия с элементами, перекрытыми футером.

8. **Загрузка файлов**
   - Автоматическая загрузка `.txt` файлов через `send_keys`.

9. **Работа с alert и confirm**
   - Принятие и обработка всплывающих окон через `browser.switch_to.alert`.

10. **Переключение вкладок**
    - Работа с несколькими вкладками браузера через `window_handles` и `switch_to.window`.

11. **Явные ожидания**
    - Использование `WebDriverWait` и expected conditions (`text_to_be_present_in_element`) для ожидания изменения элементов на странице.

12. **Git**
    - Работа с локальным репозиторием.
    - Использование команд `git status`, `git add`, `git commit`, `git log`.
    - Создание осмысленных коммитов и описание репозитория в README.
    - Рецензирование решений других студентов.

---

Все скрипты находятся в отдельных файлах с расширением `.py`, каждый файл соответствует конкретному заданию.
